# 📚 الدرس 1: شنو هو ft_irc ؟

## Goal

> تفهم شنو هو مشروع ft_irc، شنو هو IRC، علاش كاين، وكيفاش خدام بطريقة عامة — بلا ما تمس أي كود ولا أي تفصيل تقني.

---

## Explanation

### 1. شنو هو مشروع ft_irc ؟

ft_irc هو مشروع ف 42 كاتبني فيه **IRC Server** كامل من الصفر بلغة **C++98**.

يعني نتا غادي تكتب برنامج اللي كايتسنى الناس يتصلو بيه، يدخلو لغرف ديال الدردشة (**Channels**)، يهضرو مع بعضياتهم، ويديرو حاجات بحال تغيير موضوع الغرفة ولا طرد شي واحد.

**ملاحظة مهمة:** نتا غادي تبني غير الـ **Server**. الـ **Client** ما غاديش تبنيه — غادي تستعمل واحد الـ Client اللي كاين من قبل (بحال **irssi** ولا **HexChat**) باش تجربه.

البرنامج ديالك غادي يتشغل هكذا:

```
./ircserv <port> <password>
```

- **port** = رقم الباب اللي غادي يتسنى فيه الـ Server الـ Connections.
- **password** = كلمة السر اللي خاص كل Client يعطيها باش يتصل.

---

### 2. شنو هو IRC ؟

**IRC** = **Internet Relay Chat**

هاد الشي تخلق ف **1988**. هو نظام ديال الدردشة الجماعية فالإنترنت. قبل ما يكون WhatsApp، قبل ما يكون Discord، قبل ما يكون Telegram — كان **IRC**.

IRC هو **Protocol** — يعني مجموعة ديال القواعد اللي كاتقول كيفاش الأجهزة يهضرو مع بعضياتهم. بحال القانون ديال الطريق: كلشي خاصو يتبعو باش ما يكونش مشكل.

---

### 3. علاش تخلق IRC ؟

ف 1988، واحد الراجل الفنلندي اسمو **Jarkko Oikarinen** بغا طريقة باش الناس يقدرو يهضرو مع بعضياتهم **فنفس الوقت** (Real-time) عبر الإنترنت.

قبل IRC، الناس كانو كايستعملو **Email** — ولكن Email ماشي Real-time. كاتسنا بالساعات ولا بالأيام باش تجيك الرسالة.

IRC حل هاد المشكل: كاتكتب الرسالة ← كاتوصل **فالحين** ← الطرف الآخر كايجاوب **فالحين**.

---

### 4. كيفاش خدام IRC بشكل عام ؟

الفكرة بسيطة بزاف:

1. كاين واحد الـ **Server** — هو المركز ديال كلشي.
2. كل واحد عندو **Client** — البرنامج اللي كايتصل بالـ Server.
3. الـ Client كايرسل الرسالة ← الـ Server كايستقبلها ← الـ Server كايوزعها لباقي الناس.

> الـ **Server** بحال ساعي البريد: ما كايكتبش الرسالة، ولكن هو اللي كايوصلها.

---

### 5. شكون هو الـ Client وشكون هو الـ Server ؟

**الـ Server** (اللي غادي تبنيه نتا):
- هو البرنامج اللي كايبقى **شغال ديما** وكايتسنى الناس يتصلو بيه.
- كايعرف شكون متصل، شكون ف شمن غرفة (**Channel**)، وشكون عندو صلاحيات.
- ما كايبانش للمستخدم — خدام فالخلف.
- كايتسنى فواحد الـ **Port** (بحال رقم الباب).

**الـ Client** (اللي ما غاديش تبنيه):
- هو البرنامج اللي كايستعملو المستخدم.
- كايتصل بالـ Server، كايرسل الرسائل، وكايعرض الأجوبة.
- أمثلة: **irssi**, **HexChat**, **WeeChat**, ولا حتى **netcat** (`nc`).

---

### 6. شنو كايوقع ملي شي واحد كايرسل رسالة ؟

عندنا 3 أشخاص: **أحمد** و**سارة** و**يوسف** — كلهم فنفس الـ Channel اسمو `#darija`.

أحمد كايكتب: `Hello everyone!`

1. أحمد (Client) كايرسل الرسالة للـ Server.
2. الـ Server كايستقبل الرسالة.
3. الـ Server كايشوف: شكون فالـ Channel ديال `#darija` ؟ سارة ✅ يوسف ✅ أحمد (ما كايرسلهاش لراسو).
4. الـ Server كايرسل الرسالة لسارة وليوسف.
5. سارة ويوسف كايشوفو: `أحمد: Hello everyone!`

**ملاحظة:** الـ Server ما كايخزنش الرسائل القديمة. غير كايوصل وكايمشي. إلا ما كنتيش متصل، ما غاديش تشوف الرسائل اللي فاتو.

---

### 7. علاش خاصنا TCP ؟

ملي كاترسل رسالة عبر الإنترنت، الرسالة ما كاتمشيش كاملة. كاتتقسم لقطع صغار اسمهم **Packets**. هاد الـ Packets كايمشيو فطرقان مختلفين وكايوصلو فأوقات مختلفين.

**بلا TCP** — المشاكل:
- شي Packets يقدرو يتوضرو فالطريق
- يقدرو يوصلو بالترتيب الغلط
- يقدرو يتكررو
- ما عندكش ضمانة بلي الرسالة وصلات

**مع TCP** — الحلول:
- كايضمن بلي **كل Packet وصل**
- كايضمن بلي **الترتيب صحيح**
- كايضمن بلي **ما كاينش تكرار**
- إلا تواضر شي Packet، كايعاود يرسلو

**TCP** = **Transmission Control Protocol** — البروتوكول اللي كايضمن ليك بلي المعلومة توصل كاملة وصحيحة.

IRC كايخدم فوق TCP. بلا TCP، ما يمكنش يخدم IRC.

---

### 8. علاش هاد المشروع صعيب ؟

هاد المشروع صعيب حيت كايجمع بزاف ديال الحاجات فنفس الوقت:

- **Networking** — كيفاش الأجهزة كايتواصلو عبر الإنترنت
- **Sockets** — كيفاش تفتح قنوات ديال التواصل
- **Non-blocking I/O** — الـ Server خاصو يخدم مع بزاف ديال الناس فنفس الوقت بلا ما يتبلوكا
- **`poll()` / `select()`** — طريقة واحدة باش تراقب كلشي فنفس الوقت
- **IRC Protocol** — القواعد ديال IRC (الأوامر، الأجوبة، الأخطاء...)
- **Parsing** — تقرا وتفهم الرسائل اللي كاتجي من الـ Client
- **State Management** — تتبع شكون متصل، شكون فشمن Channel، شكون عندو صلاحيات...
- **Edge Cases** — الـ Client يقدر يقطع فأي وقت، يرسل رسائل ناقصين، يرسل حاجات غلط...

**تحذير:** أكبر غلط هو تبدا تكودي بلا ما تفهم. هاد المشروع خاصك تفهم كل مرحلة قبل ما تكتب حتى سطر ديال الكود.

---

### 9. شنو غادي نتعلم ملي نسالي ft_irc ؟

- كيفاش الإنترنت خدام فعلاً — TCP, IP, Ports, Sockets
- كيفاش تبني Server من الصفر — يتسنى Connections ويتعامل معاهم
- كيفاش تدير Multiplexing — تخدم مع بزاف ديال الـ Clients فنفس الوقت بـ `poll()`
- كيفاش Protocol خدام — تقرا RFC، تفهم الأوامر والأجوبة
- كيفاش تبني برنامج Robust — ما كايطيحش، كايتعامل مع كل الأخطاء
- كيفاش تنظم مشروع كبير فـ C++ — Classes, Encapsulation, Clean Code

هاد المعرفة هي الأساس ديال كل حاجة فيها Backend: Web Servers, APIs, Game Servers, Chat Apps...

## Real-Life Example

### 🏨 الفندق

تخايل واحد **الفندق** فيه بزاف ديال الغرف:

| العنصر الحقيقي | المقابل ف IRC |
|---|---|
| 🏨 الفندق | الـ **Server** (البرنامج ديالك) |
| 🚪 باب الاستقبال | الـ **Port** (المكان اللي كايدخلو منو الناس) |
| 🔑 كلمة السر ديال الفندق | الـ **Password** (خاصك تعطيها باش تدخل) |
| 🧑‍💼 الموظف ديال الاستقبال | الـ **`poll()`** — كايراقب كلشي فنفس الوقت |
| 🛎️ الغرف ديال الفندق | الـ **Channels** (`#darija`, `#gaming`...) |
| 🧳 الضيوف | الـ **Clients** (الناس اللي متصلين) |
| 📋 مدير الفندق | الـ **Operator** — عندو صلاحيات خاصة |
| ✉️ رسالة لغرفة | **Channel Message** — كل واحد فالغرفة كايشوفها |
| 💌 رسالة خاصة | **Private Message** — غير واحد كايشوفها |
| 🚫 طرد شي ضيف | الأمر **KICK** |
| 📩 دعوة لغرفة | الأمر **INVITE** |

**كيفاش كايخدم هاد الفندق:**

1. الضيف كايجي لباب الاستقبال (**Port**) وكايعطي كلمة السر (**Password**).
2. الموظف (**`poll()`**) كايقبلو وكايعطيه مفتاح (**Connection**).
3. الضيف كايختار غرفة (**Channel**) وكايدخل.
4. كل ما هضر شي واحد فالغرفة، الموظف كايوصل الكلام لكلشي فنفس الغرفة.
5. المدير (**Operator**) يقدر يطرد شي واحد، يبدل موضوع الغرفة، ولا يحبس الغرفة.

الفرق الوحيد: ف IRC، موظف **واحد** (الـ Server ديالك) كايتعامل مع **كل الضيوف فنفس الوقت** بدون ما يتبلوكا. وهاد الشي هو اللي صعيب!

## Key Takeaways

1. **ft_irc** = تبني **IRC Server** من الصفر بـ **C++98**. ما كاتبنيش Client.
2. **IRC** = Protocol ديال الدردشة Real-time تخلق ف 1988.
3. **Server** = المركز. كايستقبل، كايوزع، كايتحكم. كايخدم فالخلف.
4. **Client** = البرنامج ديال المستخدم. كايتصل بالـ Server.
5. **TCP** = كايضمن بلي الرسالة كاتوصل كاملة، بالترتيب، بلا ضياع.
6. الرسالة يقدر تجي **مقسمة** لبزاف ديال الـ Packets — خاصك تجمعها.
7. الـ Server ما كايخزنش الرسائل — غير كايوصل وكايمشي.
8. المشروع صعيب حيت كايجمع Networking + Protocol + Non-blocking I/O + State Management.
9. الأوامر اللي خاصك تطبقها: `KICK`, `INVITE`, `TOPIC`, `MODE`.
10. واحد الـ `poll()` غادي تراقب كلشي: Read, Write, Listen, Accept.

## Common Beginner Mistakes

| ❌ الخطأ | ✅ الصواب |
|---|---|
| كايبداو يكوديو مباشرة بلا ما يفهمو شنو هو IRC | خاصك تفهم الـ Protocol والمفاهيم الأساسية **قبل أي كود** |
| كايخلطو بين الـ Server والـ Client | نتا غادي تبني غير الـ **Server** |
| كايفكرو بلي IRC بحال WhatsApp | IRC **ما كايخزنش** الرسائل القديمة |
| كايقفزو مباشرة لـ Sockets بلا ما يفهمو TCP | TCP هو الأساس — بلا TCP، الـ Sockets ما عندهم معنى |
| كايفكرو بلي الرسالة كاتوصل دفعة وحدة | الرسالة يقدر تجي **مقسمة** — خاصك تجمعها |
| كايهملو الـ Edge Cases | الـ Client يقدر يدير أي حاجة غلط — خاصك تكون مستعد |

**جاوب على هاد الأسئلة بالدارجة ولا بالإنجليزية — بحالما بغيتي:**

> **1.** ف ft_irc، واش نتا كاتبني الـ Client ولا الـ Server ؟ وعلاش ؟

> **2.** أحمد رسل رسالة فالـ Channel `#cafe`. سارة متصلة فنفس الـ Channel ولكن يوسف لا. شكون غادي يشوف الرسالة ؟ علاش ؟

> **4.** علاش ما يمكنش نستعملو UDP بلاصت TCP ف IRC ؟ (تلميح: فكر فالضمانة)
